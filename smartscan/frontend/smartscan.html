Adaptive Predictive Frequency-Time
Scheduling for Electronic Support

SmartScan AI optimizes narrowband receiver sensing under strict partial observability — predicting emitter activity, tracking Bayesian model uncertainty, and minimizing interception latency over real RF recordings.

⚠️ Problem Statement
Electronic Support Challenge
Narrowband receivers have limited instantaneous bandwidth. A receiver tuned to a single slice cannot simultaneously observe the entire surveillance band. Traditional sequential scanning visits F1 → F2 → … → FN in a fixed cycle, causing high intercept latency and completely missing short bursty transmissions that occur between revisits.
Key Metrics
Interception Rate: Fraction of active emissions captured
Avg Intercept Time: Slots elapsed before first detection
False Alarm Rate (Pfa): Fraction of detections with no actual signal
Probability of Detection (Pd): True positive rate over active slots
✨ SmartScan Solution
Multi-Objective Utility Scheduling
SmartScan evaluates each candidate frequency using a weighted utility function at every decision slot:
U(f) = 0.34 * Pred + 0.15 * Uncertainty
      + 0.20 * Periodicity + 0.15 * InfoGain
      + 0.10 * Recency - 0.06 * SwitchCost
Key Properties
✅ Strict partial observability (unselected channels masked)
✅ Beta-Bayesian belief update on each observation
✅ Predictive entropy-driven uncertainty exploration
✅ Autocorrelation Pulse Repetition Interval (PRI) detection
