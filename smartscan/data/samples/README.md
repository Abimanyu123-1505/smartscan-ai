# data/samples/

This directory contains small, preprocessed DEMO samples for use without
downloading full datasets.

## Files

| File | Source | Format | Duration | Note |
|------|--------|--------|----------|------|
| demo_ism_coexistence.json | doi:10.5281/zenodo.6334794 | Preprocessed PSD JSON | 60s / 200 slots | DEMO ONLY |

## WARNING

These samples are for:
- UI development
- Algorithm debugging  
- Initial demonstrations

They are NOT suitable for:
- Research results
- Performance comparisons
- Publication

For research, download the full recordings from data/datasets.yaml and
place them under data/raw/.

## DEMO Label

Any data from this directory will be labeled "DEMO · PREPROCESSED" in the UI.
This label cannot be removed without using real full datasets.
